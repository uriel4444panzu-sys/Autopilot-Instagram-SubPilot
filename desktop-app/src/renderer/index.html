Créer ton jeton

  1. Clique sur le bouton ci-dessous pour ouvrir la page de création sur GitHub.
  2. Nom du jeton : par exemple SubPilot Control Room.
  3. Repository access → Only select repositories → choisis ton dépôt SubPilot.
  4. Permissions → Contents : Read and write, Actions : Read and write.
  5. Génère le jeton, copie-le, colle-le ci-dessous.
